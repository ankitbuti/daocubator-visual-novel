# Prototype Archaeology

What we mined from `prototypes/` (three berrry.app React web prototypes, all PC-98 themed, all CSS/emoji-only — **no bitmap assets existed to rip**).

## dao25 — "DAO '25" (governance sim) → **the spine**

- Cast: MAYA (tech, cyan), JORDAN (community, magenta), ALEX (treasury, orange), VERA (union mentor, purple), THE WHALE (antagonist). *(All six carried into DAOCUBATOR.)*
- 5-chapter structure Genesis → TGE → Governance Crisis → Attack → Resolution *(carried over, day counter and all)*.
- Stats: treasury/governance/community/decentralization/security *(remapped to the research's 5-stat model)*.
- Endings: golden/tragic/bureaucratic/dictatorship/fracture *(carried into our 8)*.
- 8-entry glossary *(seed of the Codex)*. Strict 16-color PC-98 palette *(canonical, see [[Art Style Guide]])*.
- Keeper scenes: VC veto-rights offer, Proposal #17 redistribution, whale 45% red alert, "TrueDAO" fork rebuke, three-path final vote.

## startupfounders98 — "Startup Founders '98" → **the human scenarios**

- Keeper scenes: equity-split negotiation (50/50 vs 60/40 vs vesting), honest-vs-lie runway talk, Shark VC vs Angel term sheets, pivot moment, and the whole **co-founder betrayal arc** (confrontation → truth/defensive/space → burnout talk / legal nightmare) → became Maya's Ch3 crisis.
- "WISDOM UNLOCKED" popups → merged into Lesson Learned.
- Score-formula ending + persistent endings gallery *(kept)*; chiptune Web-Audio direction *(kept as audio target)*.
- Source bugs found (do not replicate): wisdom modal always routed to `choices[0].next`; angel check added $20k instead of $200k.

## daoromance — "DAO Romance" → **relationships as governance**

- Keeper mechanic: per-character relationship meters that gate warnings/votes *(kept, de-romanced for v1)*.
- Cast donors: AIKO's idealism → merged into Jordan; DRAKE → merged into Alex; SPECTRE and ATLAS carried whole; SENATOR cut (bench for future).
- Keeper scenes: 2:47 a.m. Discord ping opener, encrypted-vulnerability DM, whale's "no strings" 500 ETH, the leak + PR-vs-investigate, the late-night "are we doing the right thing?" call *(now Ch5.5)*.
- "PROTOCOL INSIGHT" interstitials → merged into Lesson Learned. Track name "Late Night Multisig" is contractually obligated to exist.
- Source quirks: trust/security stats existed but never fed endings; rooftop bg never used *(we use it — Ch5)*.
